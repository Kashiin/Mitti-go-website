# Mitti GO Website

Static welcome page for Mitti GO, built from the supplied product, flow and architecture documents.

## Structure

```text
mitti-go-website/
  index.html
  assets/
    css/
      styles.css
    js/
      script.js
    images/
      logo-main.png
      logo-white.png
      mascot.png
      hero-family-safety.png
```

## Run locally

```powershell
python -m http.server 4173
```

Then open `http://127.0.0.1:4173`.
